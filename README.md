# Privacy Policy Hub

This repository hosts the **legal URLs** required for integrations with Meta platforms (Facebook, Instagram) and other third-party services.

## What's here

| File | Purpose |
|------|---------|
| `index.html` | Static website with the full **Privacy Policy** and **Data Deletion Instructions** |

## Hosted URLs (GitHub Pages)

Once GitHub Pages is enabled for this repository, the following URLs will be publicly accessible:

| Resource | URL |
|----------|-----|
| Privacy Policy | `https://<your-username>.github.io/politicas-privadicad/` |
| Data Deletion Instructions | `https://<your-username>.github.io/politicas-privadicad/#data-deletion` |

These URLs are intended to be submitted in the **Meta App Dashboard** under:
- **App Settings → Basic → Privacy Policy URL**
- **App Settings → Basic → User Data Deletion → Data Deletion Instructions URL or Callback URL**

## Enabling GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Source**, select the `main` branch and `/ (root)` folder.
3. Click **Save**. GitHub will publish the site at the URL shown.

## Customising the page

Open `index.html` and replace the following placeholders with your actual values:

| Placeholder | Replace with |
|-------------|-------------|
| `[App Name]` | Your application's name |
| `[contact@example.com]` | Your support / data-protection email address |

## Meta Platform Compliance

The `index.html` page includes a dedicated **Data Deletion Instructions** section that satisfies the requirements of [Meta's Platform Terms](https://developers.facebook.com/terms/). It explains:
- How users can revoke access via Facebook Settings.
- How users can submit a deletion request by email.
- What data will be deleted and the expected response time.
